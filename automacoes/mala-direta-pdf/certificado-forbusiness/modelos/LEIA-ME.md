# Coloque aqui o PDF do certificado

Este é o único arquivo que falta no repositório, e de propósito: o certificado em
branco contém a assinatura do coordenador, e este repositório é público.

Salve o PDF nesta pasta com exatamente este nome:

```
Certificado_ForBusiness_Empty.pdf
```

É o arquivo "Empty" (o vazio, sem os dados de exemplo), não o "Fill". Se o nome
for outro, ajuste a linha `modelo` em `../config.toml`.
